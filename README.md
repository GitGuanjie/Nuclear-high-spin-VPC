# Nuclear High-Spin VPC — open-source Python reproduction

This directory is a Python reimplementation of the Mathematica research notebooks in the original `Nuclear-high-spin-VPC` archive. It is intended to address Reviewer 2's request for an implementation that does not require Mathematica.

The numerical outputs under `results/` were generated by the Python code in this package. They are **not copied from the saved Mathematica notebook output cells**. The original notebooks are retained only under `legacy_mathematica/` for provenance and side-by-side comparison.

## Reviewer-2 correction

The corrected TACT benchmark uses

```text
H_TACT = chi (Ix^2 - Iy^2)
initial state = CSS_z = |I,I>
```

The OAT benchmark uses the equatorial coherent state employed in the manuscript. The corrected TACT convention is used in the Python reproductions of Figs. 2, 6, 7 and 12.

## What was converted

The shared package `vpc/core.py` replaces the repeated Mathematica definitions of `SpinMatrices`, the coherent-spin initial state, `Hmuti`, `MatrixExp` evolution, squeezing calculations, Lindblad evolution, fidelity, OAT and TACT.

Python scripts correspond to the original notebooks as follows:

| Original Mathematica notebook | Python replacement |
| --- | --- |
| `VPC Sequence search 3half2.nb`, `5half2.nb`, `7half2.nb` | `scripts/search_vpc.py`, `scripts/search_selected_phases.py` |
| `density plot profile ... .nb` | `scripts/density_profile.py` |
| `3half2SolutionCompare.nb` | `scripts/find_multiple_solutions.py` plus the common VPC functions |
| `no decoherence and linear plot.nb` | `scripts/reproduce_fig2.py`, `scripts/reproduce_fig3.py`, `scripts/reproduce_fig6_7.py` |
| `TACT and Wineland plot.nb` | `scripts/reproduce_fig12.py`, `scripts/reproduce_fig12_envelope.py` |
| `Squeeze and Cat state compare Fidelity.nb` | `scripts/reproduce_fig13.py` |

## Install

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

No Mathematica installation is needed.

## Minimal validation

```bash
python scripts/validate_core.py
```

This independently checks:

1. the Python VPC Hamiltonian against a direct matrix exponential;
2. coherent-spin-state normalization of both squeezing parameters;
3. the corrected TACT(CSS_z) minima for I=3/2, 5/2 and 7/2.

## Reproduce the reviewer-relevant figures

```bash
python scripts/search_selected_phases.py

python scripts/reproduce_fig6_7.py
python scripts/reproduce_fig12.py
python scripts/reproduce_fig12_envelope.py

```

The repository already includes Python-generated CSV/NPZ/PNG outputs in `results/` so the numerical values can be inspected without re-running the optimization.

`Fig. 2` is a time-resolved optimized lower envelope: the VPC phases are reoptimized at each displayed time, rather than one fixed phase sequence being propagated through the whole curve.

## Full-search setting

The manuscript used many random initial phase vectors. The open-source search routine exposes the same setting. For example:

```bash
python scripts/search_vpc.py --spin 3.5 --time 0.314 --metric ku --starts 2000 --out results/search_I3p5_t0314.json
```

The supplied figure-generation run uses fewer random starts plus deterministic continuation seeds so that it can finish on a normal laptop. Increase `--starts` when reproducing the full search statistics.

## Key Python-generated benchmark numbers

See `results/key_results_python.csv`. In particular, for the corrected TACT(CSS_z) benchmark:

- I=3/2: xi_S^2 = 1/3 at chi t = 0.302299894...
- I=5/2: xi_S^2 = 0.228094357... at chi t = 0.228560636...
- I=7/2: xi_S^2 = 0.180091133... at chi t = 0.181840004...

The independently optimized Python VPC calculations reproduce the speed–depth tradeoff used in the revised manuscript: TACT reaches its optimum earlier, while longer-time VPC reaches a lower KU squeezing value for I=5/2 and I=7/2.

## Units / normalization

The Python code follows the manuscript's dimensionless benchmark convention: `Omega = gamma B1/(2I) = 1` for VPC and `chi = 1` for OAT/TACT. This is a nominal coupling-scale normalization and should not be interpreted as identical hardware power or operation cost.

## Notes on the old Mathematica notebooks

The notebooks are exploratory research files and contain historical output cells and multiple intermediate definitions. The Python package follows the definitions and conventions of the **revised manuscript**, including the corrected TACT initial state and the stated KU/Wineland normalizations. Old stored notebook outputs are not treated as authoritative numerical input.
